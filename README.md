# LLM Disobedience Control Mechanisms

This example demonstrates how Large Language Model (LLM) 'disobedience' can be controlled using two distinct mechanisms: internal 'skill-based' rules and an external 'MCP Server' concept. It simulates an LLM generating responses, showing how internal logic can prevent harmful outputs, and how a separate monitoring system can act as a final safety layer to filter or block undesirable content.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
